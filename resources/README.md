# 资源库（Resources）

> 原则：**真实性 > 数量**。本目录每条资源都带完整署名（title/author/source/license）与验证状态。
> 未验证资源一律不进入本目录（它们在 [../research/unverified/](../research/unverified/)）。

## 层级（tier）

- **CORE** —— 进入正式推荐区的最高置信资源（verified + 与知识点强匹配）
- **RECOMMENDED** —— 已验证的高质量补充
- **SUPPLEMENTARY** —— 已验证但有局限（必须带 notes 说明，如"内容过时"）
- **ADVANCED** —— 进阶方向入口

## 硬性规则（CONTRIBUTING 摘要）

1. `verified: true` 必须附 `verified_date` + `verification_method`。
2. 作者未知写 `unknown`，禁止猜测。
3. 摘要为自己的话，不复制第三方原文（版权）。
4. 过时/维护停滞必须如实标注 `maintenance_status`。
