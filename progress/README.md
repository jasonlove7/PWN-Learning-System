# Progress（学习进度跟踪）

> 状态只有三种，与项目原则一致——**没有 XP、没有积分、没有打卡**：

```text
🔴 未学习   —— 还没开始
🟡 熟悉     —— 学过一遍，做题还需要 hint
🟢 已掌握   —— 能独立完成关联挑战并给别人讲清楚
```

## 使用方法

1. 复制 [PROGRESS.md](PROGRESS.md) 的表格段落到自己的 fork（或直接编辑）。
2. 每完成一个知识点，更新状态与日期。
3. 🟢 的判定标准不是"看完了"，而是该知识点关联挑战**能独立做出**。
4. 建议每 30 天回顾一次：🟡 超过 30 天未动的条目 → 安排重做关联挑战。

## 隐私

进度文件不包含任何个人信息；fork 者如需私有进度，可放入 `notebook/personal/`（已被 .gitignore 排除）。
